## Selected projects

### [RISC-V 32I, 5-stage pipelined processor (ASIC)](https://github.com/2A-SEI-Projet-RISC-V-32I/RISC-V-32I)
*Team project (3 authors) · SystemVerilog, Synopsys Design Compiler, Cadence Innovus*

RV32I core with data forwarding and hazard control, taken from RTL to routed layout in AMS 0.35 µm.
**22.9 MHz Fmax · 28 mW · ~0.96 mm² of standard cells · no setup/hold/DRC violations after routing.**

### [RISC-V RV32I multi-cycle core (FPGA)](https://github.com/Axel-TARTAVEZ/RISC-V-RV32I-Multi-Cycle-Core)
*SystemVerilog, Vivado · Spartan-7 (Urbana board)*

FSM-based, Von Neumann core running C and assembly firmware on hardware, with per-module testbenches and isolated RISC-V instruction tests.
**~81.6 MHz Fmax · under 1,500 LUTs.**

### [AI surrogate models for CFET / 2D-FET assessment](https://github.com/Axel-TARTAVEZ/AI_Modeling_of_CFETs_for_High-Performance_Chip_Assessment)
*Python, PyTorch · research internship at NYCU, Taiwan*

Neural-network pipeline replacing TCAD and SPICE runs for early design-space exploration:
typical error below 1 % on Vth and SS and about 3.5 % on Ion, with 100,000 geometries screened in a fraction of a second. Limitations and approximations are documented in the repository.
